# homebrew-tap

Homebrew formulas for Enactrs.

```bash
brew tap adl-tan-theta/tap
brew trust --formula adl-tan-theta/tap/enactrs-canary   # Homebrew tap-trust
brew install enactrs-canary                            # integration canary
```
